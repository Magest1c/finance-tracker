# Чек-лист тестирования API

## Протокол и контракт

- [x] `/health` возвращает 200 и JSON.
- [x] JSON-маршрут отклоняет отсутствующий или неверный `Content-Type`.
- [x] Некорректный JSON возвращает 400.
- [x] Неизвестные поля JSON возвращают 400.
- [x] Тела ошибок содержат единое поле `error`.
- [x] Удаление возвращает 204 без тела ответа.
- [x] Документ OpenAPI 3.1 проходит проверку.

## Аутентификация и безопасность

- [x] Пароль хранится как bcrypt-хеш и никогда не возвращается клиенту.
- [x] Email нормализуется до проверки уникальности и входа.
- [x] Неизвестный email и неверный пароль возвращают одинаковый ответ.
- [x] Защищённые маршруты требуют `Authorization: Bearer <token>`.
- [x] Невалидный токен возвращает 401.
- [x] Токен нельзя использовать совместно с `user_id` другого пользователя.
- [x] Доступ к чужому счёту, категории или транзакции возвращает 403.
- [ ] Истечение срока действия и отзыв токена — будущая область тестирования.

## Счета и категории

- [x] Пользователь должен существовать.
- [x] Валюта приводится к верхнему регистру.
- [x] Проверяется формат кода валюты.
- [x] Тип категории принимает только `income` и `expense`.
- [x] Порядок элементов коллекции детерминирован.
- [x] Пустая коллекция возвращается как `[]`, а не `null`.

## Транзакции

- [x] Обязательные идентификаторы должны быть положительными.
- [x] Сумма должна быть положительной.
- [x] Временная метка должна соответствовать RFC3339 и не быть нулевой.
- [x] Тип определяется выбранной категорией.
- [x] Счёт и категория должны принадлежать пользователю.
- [x] Фильтры по типу, счёту, категории и периоду работают совместно.
- [x] Результаты сортируются по `occurred_at` по убыванию.
- [x] Пагинация возвращает `count`, `total`, `limit` и `offset`.
- [x] Пустой PATCH отклоняется.
- [x] Изменение и удаление отсутствующей транзакции возвращает 404.

## Отчёты

- [x] Месяц передаётся в формате `YYYY-MM`.
- [x] Счёт должен принадлежать аутентифицированному пользователю.
- [x] Доход, расход, баланс и количество рассчитываются правильно.
- [x] Начало месяца включается, конец периода исключается.

## Эксплуатационные проверки

- [x] Проверка форматирования Go автоматизирована.
- [x] Статический анализ автоматизирован.
- [x] В CI включён детектор гонок данных.
- [x] Тесты по методу чёрного ящика автоматически запускают API.
- [x] Docker-образ проходит дымовое тестирование.
