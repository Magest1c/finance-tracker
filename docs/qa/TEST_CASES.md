# Основные тест-кейсы

| ID | Сценарий | Ожидаемый результат | Автоматизация |
|---|---|---|---|
| AUTH-001 | Регистрация с валидным нормализуемым email | 201, созданный `id`, нормализованный email, пароль отсутствует в ответе | Go: интеграционный + black-box |
| AUTH-002 | Повторная регистрация email в другом регистре | 409 | Go: интеграционный + black-box |
| AUTH-003 | Вход с неверным паролем или неизвестным email | Одинаковая ошибка 401 | Go |
| AUTH-004 | Вызов защищённого маршрута без токена | 401 | Go: интеграционный + black-box |
| AUTH-005 | Использование токена пользователя B с `user_id` пользователя A | 403 | Go |
| VAL-001 | Отправка некорректного JSON | 400, единый формат ошибки | Go |
| VAL-002 | Отправка неизвестного поля JSON | 400 | Go: интеграционный + black-box |
| VAL-003 | Отправка тела без JSON `Content-Type` | 415 | Go |
| ACC-001 | Создание счёта с кодом валюты в нижнем регистре | 201, валюта возвращается в верхнем регистре | Go |
| CAT-001 | Создание категорий дохода и расхода | 201, корректный тип | Go: интеграционный + black-box |
| TX-001 | Создание доходной и расходной транзакции | 201, тип определяется категорией | Go: интеграционный + black-box |
| TX-002 | Фильтрация по типу и диапазону дат | Только подходящие элементы и корректные метаданные | Go: интеграционный + black-box |
| TX-003 | Проверка `limit` 0/1/100/101 и `offset` -1/0 | Границы принимаются или отклоняются согласно требованиям | Go: интеграционный + black-box |
| TX-004 | Изменение суммы и строки описания с пробелами | 200, поля изменены, пробелы удалены | Go: интеграционный + black-box |
| TX-005 | Удаление транзакции | 204 без тела; последующее изменение возвращает 404 | Go: интеграционный + black-box |
| SEC-001 | Создание транзакции с чужим счётом | 403 | Go: интеграционный + black-box |
| REP-001 | Расчёт месячного отчёта | Корректные доход, расход, баланс и количество | Go: интеграционный + black-box |
| CTR-001 | Валидация документа OpenAPI | Ошибки спецификации отсутствуют | Go, `kin-openapi` |
| OPS-001 | Запуск собранного контейнера и опрос `/health` | Ответ 200 в течение 30 секунд | GitHub Actions |
